# Privacy disclosure

**Last updated: October 18, 2026**

Navorika Tools is a Chrome extension that provides shortcuts to selected tools on `navorika.com`.

## Data handled by the extension

The extension stores the IDs of tools you mark as favorites in Chrome's local extension storage so those favorites remain available when you reopen the popup. It does not collect, transmit, sell, or share this preference data. The extension does not read the pages you visit, inspect page content, capture browsing history, or access files.

## Network activity

The extension itself makes no network requests. When you choose a shortcut, Chrome opens the corresponding Navorika page in a new tab. That page is governed by the privacy information shown on Navorika and may use its own network or processing behavior, which is described on the page.

## Permissions

The `storage` permission is used only to save favorite tool IDs locally. The extension requests no host permissions.

## Contact

For questions about this extension, use the contact information on [Navorika](https://navorika.com/about).
