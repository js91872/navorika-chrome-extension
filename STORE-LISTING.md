# Chrome Web Store listing draft

**Name:** Navorika Tools

**Short description:** Open Navorika's image, CSS, PDF, and CAD tools from your Chrome toolbar.

**Category:** Productivity

**Detailed description:**

Keep useful browser-based utilities close at hand. Navorika Tools gives you a compact launcher for image preflight, responsive CSS, PDF print checks, and CAD conversion workflows.

Included shortcuts:
- RGB / CMYK Image Checker
- CSS Flexbox Generator
- Aspect Ratio Padding Calculator
- PDF Bleed & Trim Checker
- STEP to 3D PDF converter
- CorelDRAW converters
- Browse all Navorika tools

Search by tool name or category, and star the tools you use most. Favorites are saved locally in Chrome. The extension does not read your browsing activity or page content and does not make network requests. Opening a shortcut takes you to the corresponding tool on navorika.com, where that tool's own processing and privacy details apply.
